# MAX Prank

Шуточное Android-приложение, которое притворяется страницей установки мессенджера **MAX** (`ru.oneme.app`) из Google Play. После выдачи разрешения «Поверх других приложений» приложение поверх рабочего стола рисует диалог установки с логотипом MAX. Кнопка **Установить** через ~1.5 секунды нажимается сама, дальше идёт фейковый прогресс-бар установки и появляется кнопка **Открыть** с надписью «это пранк 😄».

## Что внутри

- `MainActivity` — UI с двумя кнопками: «Дать разрешение» и «Запустить пранк». Контролирует наличие `SYSTEM_ALERT_WINDOW`.
- `FakeInstallOverlayService` — foreground-сервис, который добавляет в `WindowManager` оверлей типа `TYPE_APPLICATION_OVERLAY`. Внутри лежит layout `overlay_fake_install.xml`, имитирующий карточку Google Play.
- После запуска оверлея активность отправляет пользователя на домашний экран, чтобы окно «висело» поверх лаунчера.

## Иконка

В качестве иконки приложения и иконки в карточке-пранке используется реальное лого MAX (480×480 PNG), разложенное по плотностям:

- `app/src/main/res/drawable/ic_max_logo.png` — карточка-пранк.
- `app/src/main/res/mipmap-{m,h,xh,xxh,xxxh}dpi/ic_launcher{,_round}.png` — launcher-иконка.
- `app/src/main/res/drawable-xxxhdpi/ic_launcher_foreground.png` + `mipmap-anydpi-v26/ic_launcher.xml` — adaptive-icon (фон `@color/iconBackground` = `#6895EE`).

## Как собрать

1. Открыть проект в Android Studio (Giraffe+).
2. Дать собрать Gradle.
3. Запустить на устройстве с Android 6.0+.
4. В приложении нажать «Дать разрешение» → разрешить «Поверх других приложений» → «Запустить пранк».

## Как остановить

- Свайпнуть приложение из «недавних» — foreground-сервис остановится и оверлей пропадёт.
- Либо тапнуть кнопку **Открыть** в финальном экране пранка — сервис закроется сам.

## Дисклеймер

Это безобидная шутка: ничего не устанавливается, никаких прав сверх оверлея не запрашивается, никакие данные никуда не отправляются. Используйте только с теми, кто оценит юмор.
